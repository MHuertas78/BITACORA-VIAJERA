BITÁCORA VIAJERA - ACTIVIDAD 1

Archivos:
- index.html: estructura y contenido del blog.
- estilos.css: diseño visual y adaptación a dispositivos móviles.
- script.js: buscador, filtros, modo oscuro, desplegables y validación del formulario.

Ejecución local:
1. Mantener los tres archivos en la misma carpeta.
2. Abrir index.html con un navegador moderno.
3. No se requieren dependencias, servidor, base de datos ni conexión a Internet.

Publicación sugerida:
Subir los archivos a un repositorio de GitHub y activar GitHub Pages. Después, sustituir en la memoria el texto pendiente por la URL pública.
