BITÁCORA VIAJERA - ACTIVIDAD 1

Descripción:

Bitácora Viajera es un blog diseñado para compartir experiencias de viaje,
recomendaciones turísticas y consejos prácticos para viajero
Tecnologías utilizadas:
- HTML5
- CSS3
- JavaScript

Archivos:
- index.html: estructura y contenido del blog.
- estilos.css: diseño visual y adaptación a dispositivos móviles.
- script.js: buscador, filtros, modo oscuro, desplegables y validación del formulario.
